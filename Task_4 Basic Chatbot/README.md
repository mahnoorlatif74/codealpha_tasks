# CodeAlpha Internship – Task 4

## Basic Chatbot 🤖

This project is developed as part of the **CodeAlpha Python Programming Internship – Task 4: Basic Chatbot**.

The chatbot is a simple **rule-based Python chatbot** that responds to predefined user messages using conditional statements.

## 📌 Project Description

This chatbot interacts with the user through the terminal/console. It recognizes common messages such as greetings, questions about the chatbot, thanks, and goodbye messages.

If the chatbot does not recognize the user's input, it provides a default response.

## ✨ Features

* Responds to greetings such as `hello`, `hi`, and `hey`
* Responds to "how are you?"
* Tells the user its name
* Explains what it is
* Responds to "thank you" and "thanks"
* Ends the conversation when the user types `bye`, `goodbye`, `exit`, or `quit`
* Provides a default response for unknown messages
* Uses Python functions, conditional statements, loops, and user input

## 🛠️ Technologies Used

* **Python 3**
* Conditional statements (`if`, `elif`, `else`)
* Functions
* `while` loop
* User input and console output
* String methods such as `lower()` and `strip()`
