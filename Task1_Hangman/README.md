# Task 1: Hangman Game

## Description

This is a simple text-based Hangman game developed using Python.

The player guesses a randomly selected word one letter at a time.

## Features

- 5 predefined words
- Random word selection
- Maximum 6 incorrect guesses
- Console-based gameplay
- User input for guessing letters

## Concepts Used

- Python
- Random module
- Lists
- Strings
- While loop
- If-else statements
- User input

## How to Run

Run the following command:

python hangman.py
